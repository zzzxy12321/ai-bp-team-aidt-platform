## ⚠️ 冻结时已知问题

### P0

1. `project-manager` 缺少 `workflow-task:approve/return/terminate`。
2. 事件分析/确认状态和 `AnalysisRunId` 未持久化。
3. 项目状态变更未持久化。

### P1

4. 文件上传后未自动形成项目证据关系。
5. 数字员工截止日期识别偏移一天。
6. 已完成流程任务仍出现在“我的待办”并保留操作按钮。

## 🧾 已证明能力

- 项目、任务、附件、事件、审计和配置版本可以持久化。
- 配置中心可以创建、校验、发布和回滚。
- 发布配置可以生成并执行 WorkflowVersion。
- 研发、质量、平台管理员兼岗经理可以完成三节点流程。
- 普通研发和质量岗位无法越权进入配置中心。
- 审计可以记录流程启动和人工审批。
