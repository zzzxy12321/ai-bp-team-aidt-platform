# AGT-003-B 影响分析

## 变更目标

在 AGT-003-A 后端能力之上完成真实身份中心 UI、证据链展示、流程配置和 MCP 中心联动。

## 涉及功能 ID

- `AGT-003 / 6B`：数字员工身份中心
- `AGT-001`：数字员工运行与人工确认
- `AGT-002`：受限代理和停用状态
- `WFROLE-001`：流程 Agent 节点
- `MCP-001`：MCP 服务身份、客户端和令牌
- `IAM-001`：平台管理员与部门负责人权限
- `AUD-001`：审计与证据

## 前端影响

- 重写 `AgentPage`：身份列表、筛选、表单、版本、高风险复核、运行与证据详情。
- 新增 `AgentIdentityEditor`、表单模型和业务语言映射。
- `ConfigurationCenterPage` / `WorkflowPoliciesPage` 只显示有效发布身份，改用名称、等级、
  风险和稳定编码，不显示裸 UUID。
- `McpCenterPage` 展示关联数字员工、生命周期可用性、令牌状态和撤销原因。

## API 影响

- 扩展 Agent 详情 `LastRunAt`、`RecentRunCount`。
- 新增 `GET /api/v1/agents/options`。
- 新增 `GET /api/v1/agents/{id}/context`。
- MCP 客户端/令牌概要增加关联身份名称和可用状态。
- 不改既有生命周期端点语义，保持 `/agents?run=...` 深链。

## 数据与权限影响

- 无表结构新增；新增 016 迁移仅授权供应链、财务、生产角色读取有效数字员工。
- 普通业务人员仍只能读取授权部门中有效已发布身份。
- MCP 详情和审计时间线只向有管理权限的部门负责人/平台管理员返回。
- 服务身份不能登录治理页面、审核自己或完成真人确认。

## 安全影响

- API 不返回令牌明文、TokenHash、密钥、物理路径或完整敏感材料。
- 工具选择来自后端注册表；永久人工边界固定展示。
- 高风险发布和回滚进入现有双人审核；前端不能绕过。

## 测试范围

- 表单和业务文案单元测试、页面状态 Vitest。
- AGT-003 API/SQL 全量回归、MCP 全量回归、OpenAPI、类型检查和生产构建。
- 源码及正式 E2E：完整网页生命周期、刷新/重登、部门边界、普通只读、
  高风险审核、停用联动流程和 MCP、AgentRun 反查、深链和三档响应式。
- 016 up/down/re-up、应用回滚、数据库备份与独立恢复。

## 回归风险

- 既有 AgentPage E2E 依赖按钮和运行表格，需要保留稳定测试标识与行为。
- 流程配置选择器由名称/ID混用改为业务标签，需要覆盖已有项目经理审批流程。
- MCP 中心新增身份列可能造成窄屏表格溢出，需要 1280/390 验证。
- 016 只增加读取权限，不放大创建、发布或运行能力。

## 源码验证结论

- 响应式表单对象不能直接使用浏览器 `structuredClone`；已改为显式表单快照复制。
- `?run=` 深链必须自动切换运行记录页签，同时保留旧运行按钮的稳定测试标识。
- 项目状态更新提示必须晚于详情刷新，避免连续状态变更使用旧版本。
- 流程配置处理人策略增加稳定测试标识，避免布局变化导致选择器误点。
- 上述修复均已在完整 45 项源码 E2E 中回归通过。
