# UX-006 全站主栏目页面介绍与具体业务示例变更计划

状态：`in_progress`

## 🎯 目标

在 UX-005 已经冻结的固定侧栏和统一工作台框架上，为所有可从左侧主导航进入的
一级栏目提供一致、可访问、内容准确的业务介绍。页面头保持简洁；用途、适用岗位、
操作路径、具体例子、数据来源、权限范围和人工安全边界统一进入右上角“介绍”抽屉。

本功能只改变前端帮助内容、页面头和共享组件，不改变后端 API、数据库、权限语义、
流程事务或审计规则。

## 🧱 统一组件

- 保留并扩展 `WorkbenchIntroDrawer.vue`，作为唯一介绍抽屉实现。
- 扩展 `WorkbenchPageHeader.vue`，作为唯一一级栏目页面头结构。
- 新增 `MainColumnPageHeader.vue`，组合页面头、介绍目录、抽屉状态、焦点返回和链接跳转。
- 新增 `frontend/src/features/workbench-intro/introCatalog.ts`，集中维护 17 个栏目的静态介绍。
- 现有“我的工作”“AI 听记”从页面内文案迁移到同一目录，删除重复抽屉代码。

## 🖥️ 页面头规范

左侧显示：

- 页面标题；
- 当前部门或数据范围短句。

右侧显示：

- 页面已有主操作；
- “介绍”文字按钮。

正文不再长期放置大段功能介绍。付款、质量放行、配方、设备、合同和赔付等现场风险
提示继续保留在实际操作附近。

## 📚 介绍内容规范

每个目录项至少包含：

1. 页面用途；
2. 适用岗位与典型时机；
3. 3—5 步真实操作路径；
4. 至少两个具体到操作和结果的业务例子；
5. 数据来源；
6. 权限范围；
7. 人工确认与安全边界；
8. 建议下一步；
9. 可选相关入口。

内容只描述当前已实现能力。当前系统仍为 Demo 身份、手动听记、规则模拟 Agent、
Mock/Disconnected 外部系统，介绍中不得写成已连接生产系统或真实外部模型。

## ♿ 交互与布局

- 桌面右侧宽约 `420px`；
- 小屏全屏或接近全屏；
- 点击关闭、点击遮罩、按 Escape 均可关闭；
- 关闭后焦点返回当前页面“介绍”按钮；
- 抽屉使用 `role="dialog"`、`aria-modal` 和标题关联；
- 抽屉内部独立滚动，不产生内部横向滚动；
- 长内容可滚动到底；
- 320、390、600、820、1280、1366 和 1920 宽度下无页面横向溢出。
