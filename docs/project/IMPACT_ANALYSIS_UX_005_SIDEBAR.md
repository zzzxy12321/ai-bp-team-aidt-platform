# UX-005 PMS 风格侧边栏与工作台正文重构影响分析

## 🎯 变更目标

统一 AIDT 的侧栏、页面头、统计、筛选、分类和主体内容布局，降低认知负担，
并修复裁切、滚动消失、固定窄宽和窄屏超长导航问题。

## 🧩 涉及功能

- `UX-005`：PMS 风格侧边栏与工作台正文重构
- `UX-001`：我的工作
- `MIN-001`：AI 听记
- `NAV-001`：仅消费现有导航树与个人偏好
- `PLT-002`：仅消费权限过滤结果
- `DEPT-WF-001`：共享应用布局

## 🖥️ 前端影响

### UX-005-A

- `AppLayout.vue`：全高应用壳、固定侧栏、独立滚动、抽屉和焦点管理。
- `tokens.css` / `style.css`：侧栏、页面宽度、滚动和响应式 token。

### UX-005-B

- 新增或整理页面头、介绍抽屉、统计条和筛选栏的复用结构。
- 全局 `.main-content` 不再对所有页面固定 `1260px`。
- 运营页与阅读页分级设置宽度。

### UX-005-C

- `MyWorkPage.vue`：全宽事项列表、统计、搜索、组合筛选和分类。
- `MinutesPage.vue`：统计、搜索、筛选、固定高度左右分栏。
- 页面说明迁移到介绍抽屉。

## 🌐 API 影响

### 默认

- 不修改现有 API/DTO/OpenAPI。
- 导航和偏好继续使用现有接口。
- “我的工作”和“AI 听记”优先复用现有响应。

### 条件性只读扩展

若真实统计无法从现有响应准确取得：

- 允许新增最小只读汇总字段或接口；
- 必须避免按当前页条数估算全量；
- 必须先更新契约、权限和测试；
- 不得修改写接口或业务事务。

### 实际只读契约（C2）

- `GET /api/v1/minutes` 新增可选筛选参数：`search`、`departmentId`、`status`、
  `actionItemStatus`、`sourceType`、`meetingFrom`、`meetingTo`。
- 新增 `GET /api/v1/minutes/summary`，返回当前授权范围内的听记总数、已分析数、
  待确认行动项数和本周新增数。
- 仍要求 `minutes:Read`，并复用原有组织、部门、环境数据范围过滤。
- 未新增或修改写接口、业务事务、审计动作、权限语义或数据库迁移。

## 🗄️ 数据库影响

- 默认无表结构变更。
- 若查询性能因筛选下降，只能通过必要的只读索引迁移解决，并单独记录。
- 不复制事项、听记、任务或业务对象状态。

## 🔐 权限和审计影响

- 所有统计、搜索结果和筛选选项继续遵循原数据范围。
- 导航、事项和听记权限仍以后端为准。
- 不在前端显示无权限数据。
- 本需求不改变写操作和审计规则。

## ♿ 交互和可访问性影响

- 侧栏抽屉、介绍抽屉和筛选控件必须支持键盘。
- “介绍”按钮需有明确可访问名称。
- 介绍抽屉关闭后焦点返回触发按钮。
- 当前导航使用 `aria-current="page"`。
- 可折叠分组使用 `aria-expanded`。
- 状态不能只用颜色表达。

## 🧪 测试范围

### 基础组件

- 页面头操作区布局；
- 介绍抽屉打开、关闭、焦点返回；
- 统计卡数值和空状态；
- 筛选栏重置；
- 侧栏单开分组和导航滚动。

### 我的工作

- 四个统计；
- 搜索和组合筛选；
- 全部及四类页签；
- 事项打开；
- 无结果、加载失败和跨环境状态；
- 快速创建入口保持可用。

### AI 听记

- 四个统计；
- 搜索和组合筛选；
- 列表选择与详情对应；
- 左右区域独立滚动；
- 导入、分析、行动项保存和确认动作不回归。

### 响应式

- `1920×1080`、`1440×900`、`1280×720`；
- `600×518` Codex 侧栏；
- `390×844` 移动端；
- 无横向溢出，筛选项可换行或收纳。

## ⚠️ 主要风险

| 风险 | 应对 |
|---|---|
| 全宽后表格过长难扫读 | 限制列宽、固定表头、冻结关键列和合理内边距 |
| 统计不真实 | 优先读取真实汇总；无法取得时先缩小样板范围或增加只读 API |
| 说明移走后用户不会操作 | 介绍抽屉提供场景和实例；关键风险仍在操作位置提示 |
| 一次性改全站导致回归 | 先 A/B/C，首批只改我的工作与 AI 听记 |
| 左侧列表仍然无限增长 | 固定高度、独立滚动、分页或虚拟列表 |
| 移动端筛选过密 | 首行搜索，其余筛选收进“筛选”抽屉 |
| 新旧测试依赖标题说明文案 | 保留稳定 `data-testid`，将断言改为业务标题和真实结果 |

## ↩️ 回滚方式

- A、B、C 分开提交和验证。
- 回滚侧栏不影响业务数据和权限。
- 回滚页面框架不影响 API 和数据库。
- 回滚我的工作/AI 听记时保留原业务动作和测试标识。
