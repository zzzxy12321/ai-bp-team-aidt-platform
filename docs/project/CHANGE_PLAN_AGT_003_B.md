# AGT-003-B 数字员工身份中心前端与业务联动变更计划

状态：COMPLETE_DEPLOYED_AND_FROZEN

## 🎯 目标

将 `/agents` 从运行记录页升级为业务人员可理解、可操作和可追溯的数字员工身份中心。
全部生命周期操作真实调用 AGT-003-A API，刷新和重新登录后仍从 SQL Server 读取。

## 🧩 Feature 与发布

- Feature：`AGT-003 / 6B`
- 功能分支：`feature/ui-step6b-agent-identity-ui`
- 基线：`main@337dd51`
- 前置冻结：`req-ui-step5-frozen-v1`、`req-ui-step6a-frozen-v1`
- 目标发布：`req-ui-step6-final1`
- 目标冻结：`req-ui-step6-frozen-v1`

## ✅ 范围

1. `/agents` 身份卡片/表格、搜索、部门与生命周期筛选、概览和运行入口。
2. 新建、复制、编辑草稿、保存、校验、发布、停用、恢复、版本和回滚。
3. 七组表单：基本信息、组织负责人、服务账号、自主限额、工具能力、人工边界、数据模型。
4. 后端输出已注册能力、风险、确认要求和永久人工边界；前端只允许选择这些能力。
5. 详情聚合当前版本、版本历史、近期运行、流程节点、WorkflowTask、MCP 客户端/令牌、
   Gateway 调用、审计时间线；不返回任何令牌明文或密钥。
6. 流程配置和岗位策略只显示当前有效已发布身份，显示名称、业务说明、等级和稳定编码。
7. MCP 中心展示关联数字员工、客户端、作用域、令牌状态、撤销原因和最近使用。
8. `/agents?run=...` 继续可定位运行；历史运行在身份停用后仍可打开和追溯。
9. 覆盖 Loading、Empty、Error、Denied、Conflict、NotPublished、Inactive、
   PendingReview、ValidationFailed 等状态。
10. 新增 016 增量权限迁移，向供应链、财务和生产业务角色授予有效身份只读权限。

## 🔌 后端补充

- `GET /api/v1/agents/options`：当前操作者可见的部门、真人负责人候选、未绑定服务账号、
  已注册能力及边界元数据。
- `GET /api/v1/agents/{id}/context`：运行、流程节点、流程任务、MCP、Gateway 和审计证据聚合。
- Agent 概要增加最近运行时间与次数；MCP 客户端/令牌概要增加关联身份名称和可用状态。

## 🚫 非目标

- 不新增第二套身份、权限、OAuth、MCP、审计或令牌系统。
- 不连接真实钉钉、U9、ERP、DCS，不调用真实外部模型。
- 不开放任意 SQL、Shell、HTTP、文件系统或代码执行工具。
- 不允许数字员工付款、质量放行、修改批准配方、控制设备、解除安全联锁、
  承诺外部合同或处理客户重大赔付。
