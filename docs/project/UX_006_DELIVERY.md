# UX-006 全站主栏目页面介绍与具体业务示例交付报告

状态：`complete_deployed_and_frozen`

## 🎯 交付结论

17 个左侧主导航一级栏目已经统一使用同一个页面头组合组件和集中式介绍目录。
每个页面右上角均提供“介绍”入口，抽屉包含页面用途、适用岗位、典型时机、
3—5 步业务操作路径、至少两个具体业务例子、数据来源、权限范围、人工确认与
安全边界、建议下一步以及相关入口。

本批不修改后端 API、数据库、权限语义、流程事务或审计写入规则。介绍内容为前端
静态帮助，不读取额外业务数据，也不写审计。

## 🐞 回归修复

审计页原实现只读取最近 100 条审计事件后在浏览器内按实体过滤。历史数据超过一页时，
目标实体可能被截掉并错误显示 0 条。现改为直接使用后端已支持的 `entityType`、
`entityId` 查询参数，不新增 API、表或权限。对应 WF-001 刷新审计场景已复测通过。
