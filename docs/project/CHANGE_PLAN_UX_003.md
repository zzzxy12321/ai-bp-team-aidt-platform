## 🎯 目标

将流程任务、项目任务、待确认事件、听记行动项、MCP 真人确认和 Agent 待确认运行统一投影到
员工“我的工作”，减少跨页面寻找，同时不复制业务状态。

## 🧱 实施范围

1. 新增 `WorkItemViewDto` 和 `MyWorkSummaryDto`。
2. 扩展 `GET /api/v1/my-work` 为跨模块只读聚合。
3. 增加统一中文状态、风险、优先级分组、来源数量和详情深链。
4. 去重：事件已有生成任务时，任务优先；关联流程任务的项目任务在同一用户视图中让位。
5. 排序：永久人工边界、已逾期、今天到期、等待确认、本周、其他。
6. 重构“我的工作”页面，保住真实发起事项和文件能力。
7. 为事件、听记、Agent 页面增加查询参数聚焦。

## 🚫 不在范围

- 不改后端业务状态机或数据库结构，除非实现中发现不可绕过的索引问题。
- 不新增第二套待办表。
- 不改变事件确认、项目任务完成、听记行动项确认、MCP 真人确认和 Agent 确认的现有语义。
- 不接真实外部系统或外部模型。

## 🧪 验证

- 单元测试：状态中文、风险、排序、去重。
- SQL/API：六类来源聚合、事件/任务去重、完成项排除、跨部门隐藏、重新登录稳定。
- 前端：类型、Vitest、OpenAPI、生产构建。
- E2E：桌面 1440、桌面 1280、移动 390，详情深链。
- 发布：干净提交构建、部署、健康检查、回滚和恢复。
