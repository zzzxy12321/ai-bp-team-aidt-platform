# SCN-001-B 变更计划

> Feature：`SCN-001 / 7B`
>
> 分支：`feature/ui-step7b-scenario-center-ui`
>
> 目标发布：`req-ui-step7-final1`
>
> 冻结标签：`req-ui-step7-frozen-v1`

## 🎯 目标

在 7A 已交付的场景目录和受控启动后端之上，建设 `/scenarios` 岗位业务场景中心。
普通员工无需理解对象、流程、任务、文件、听记和 Agent 技术模块，即可按业务目标：

1. 找到当前岗位可办理的事项。
2. 看清需要准备的材料和审批责任。
3. 通过七步向导真实发起业务链。
4. 在“我的场景”看到由现有业务真源计算出的进度和下一步。
5. 从证据入口回到既有对象、流程、任务、项目、文件、听记和审计详情。

## ✅ 本段范围

- 新增 `/scenarios` 首页、详情、启动向导和“我的场景”工作视图。
- 首页支持搜索、部门、岗位/角色、分类、推荐、我发起过、最近进行中、可用状态。
- 卡片展示业务名称、适用岗位、说明、步骤、材料、审批、数字员工、风险、可用性。
- “我的场景”只读聚合真实启动、业务流程实例、任务、项目任务、事件、文件和审计链接。
- 新增当前用户场景启动列表 API，由服务端从 SQL Server 真源计算摘要，不维护第二套进度。
- 配置中心增加场景配置入口，复用 7A 草稿、校验、发布、停用、恢复、版本和回滚 API。
- 场景资源选择只读取已发布对象类型、有效流程版本、已发布数字员工和受控附件/听记。
- 部门/岗位工作台增加“业务场景”卡片入口，并跳到同一个 `/scenarios` 页面。
- 六类场景各保留受控 Demo 样例标识，页面不把样例描述成生产事项。
- 七步向导调用真实对象、文件、听记、流程、事件、项目任务和 Agent 服务。
- 覆盖 Loading、Empty、Error、Denied、Disabled、Missing*、ValidationFailed、Conflict、
  DuplicateSubmission，并给出业务语言和下一步处理责任。
- 桌面 1440、1280 与移动 390px、类型检查、Vitest、构建、源码 E2E、正式部署 E2E。
- 全量后端/SQL/API、MCP、OpenAPI 回归，干净构建、应用回滚和数据库独立恢复。
- 更新需求池、功能地图、权限矩阵、测试证据、交付报告和规划文件。

## 🚫 非目标

- 不建设第二套业务对象、流程、任务、权限、文件、审计或 Agent 系统。
- 不在浏览器保存或推导场景业务进度、流程状态或任务状态。
- 不连接真实钉钉、U9、ERP、DCS 或真实外部大模型。
- 不允许数字员工自动确认、审批、付款、质量放行、修改批准配方、控制设备或关闭项目。
- 不修改或移动冻结标签、历史发布包和迁移 001–017。

## 🧱 前后端接缝

| 层 | 责任 |
|---|---|
| 7A 场景 API | 目录、详情、版本、校验、生命周期、预检、启动和启动详情 |
| 新增只读聚合 API | 当前用户启动列表；从启动映射反查真实流程任务、对象、项目任务、事件和进度 |
| 现有业务 API | 对象详情、流程时间线、任务动作、项目、文件、听记和审计 |
| Vue 场景中心 | 业务呈现、筛选、向导、错误映射和深链；不保存业务状态 |
| 配置中心 | 引用已注册资源并调用 7A 治理 API |

## 🔐 权限

- 普通业务角色可读取和启动部门适用范围场景。
- 平台管理员可治理全组织场景。
- 获授权部门负责人仅治理授权部门。
- 高风险采购、财务和质量场景发布继续复用双人审核。
- 启动后的任务处理继续由原流程/项目任务权限、处理人、部门范围和人工边界决定。
- 普通用户界面不显示 WorkflowDefinition ID、节点代码、TraceId、权限编码、Token 或物理路径。

## 🧪 验证计划

- 六类场景可见性、预检和真实启动。
- 启动后刷新及重新登录仍可读取同一 SQL Server 启动记录。
- 文件上传、听记来源、对象、项目任务和流程关联可追溯。
- 必填材料缺失、流程失效、Agent 失效、跨部门和无权限均以业务语言阻断。
- 数字员工只生成建议/草稿/风险提示，不自动确认。
- 采购、财务、质量永久人工边界可见且服务端不可绕过。
- 部门经理和项目经理可完成各自节点。
- 停用后不可新启动，历史启动仍可查。
- 草稿到发布、停用、恢复、版本新增和回滚生命周期。
- 1440、1280、390px；原 45/45 正式 E2E 无回归。
