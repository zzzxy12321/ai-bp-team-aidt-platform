## 🧩 六类基础场景

1. 研发样品到转产：创建 `CUSTOMER_SAMPLE` 主对象并启动
   `CUSTOMER_SAMPLE_TO_PRODUCTION`。
2. 采购请购到到货验收：创建 `PURCHASE_REQUEST` 并启动
   `PURCHASE_TO_PAYMENT`，付款节点人工。
3. 财务付款人工复核：选择真实采购请购并启动
   `FINANCE_PAYMENT_REVIEW`，永不自动付款。
4. 部门经理事项分派与审批：创建真实事件收件箱记录，后续由经理真人确认。
5. 项目经理里程碑与风险：在真实项目中创建项目任务并关联来源证据。
6. 质量异常到 CAPA：创建 `QUALITY_DEVIATION` 并启动
   `BATCH_DEVIATION_CAPA`，质量放行人工。
