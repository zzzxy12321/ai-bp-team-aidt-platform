# UX-006 全站主栏目页面介绍影响分析

## 🎯 变更结论

本批是在现有前端页面头上增加统一帮助入口，并集中整理静态业务介绍。页面业务查询、
写操作、权限校验、流程、审计和数据持久化保持不变。预计无数据库迁移、无 API 契约
变化、无后端源码变化。

## 🧩 影响范围

### 新增

- 集中式介绍目录与类型定义；
- 组合式主栏目页面头；
- 17 栏目覆盖测试；
- 介绍抽屉可滚动和焦点回归测试；
- 发布视觉矩阵与交付证据。

### 修改

- 扩展 `WorkbenchPageHeader`：支持环境标签、动态范围内容和无障碍标题。
- 扩展 `WorkbenchIntroDrawer`：支持适用岗位、时机、操作路径、数据来源、权限、
  安全边界、下一步和相关入口。
- 17 个一级栏目页面：替换旧页面头，移除正文长期大段说明，保留主操作和现场风险提示。
- 功能地图与需求池：登记 `UX-006`。
- 规划与交付文档：记录测试、部署、回滚、恢复、SHA256 和冻结标签。

## 🌐 API 与契约

- 不新增、不删除、不修改 REST API。
- 不修改 OpenAPI DTO、查询参数、响应结构或错误码。
- 页面介绍不调用 API，也不改变页面数据加载。
- 预计 OpenAPI 路径和 operationId 数量保持不变。

## 🗄️ 数据库与事务

- 无迁移、无表、无索引、无种子数据变更。
- 无业务事务、幂等或审计写入变化。
- 最大已知迁移仍为 `018`。
- 部署仍执行备份和恢复验证，作为发布证据。

## 🔐 权限影响

- 不修改权限目录、角色、数据范围或路由守卫。
- 介绍入口随页面组件渲染，因此只有通过路由权限校验后才能看到。
- 页面介绍只描述权限原则，不读取或展示具体授权数据。
- 后端仍是对所有业务读取和写操作的最终授权边界。

## 🎨 视觉与交互影响

### 桌面

- 页面标题、范围和主操作继续位于首屏。
- “介绍”按钮固定在操作区末尾。
- 说明文字离开正文，首屏业务内容向上移动。

### 小屏

- 页面头在窄屏纵向排列，操作区换行。
- 抽屉在 720px 以下占据全屏或接近全屏。
- 标题、路径和例子长文本自动换行。

### 可访问性

- 介绍按钮使用原生 button；
- 抽屉使用 `role="dialog"`、`aria-modal="true"` 和标题关联；
- Escape、关闭按钮和遮罩均可关闭；
- 打开后焦点进入关闭按钮；
- 关闭后焦点回到页面“介绍”按钮；
- 抽屉内部独立滚动，必要时加入焦点陷阱和背景滚动锁定。

## ⚠️ 主要风险

| 风险 | 应对 |
|---|---|
| 介绍文案夸大未实现能力 | 目录测试 + 人工对抗式审查；当前仅 Demo/规则模拟 |
| 17 页重复代码导致漂移 | 集中目录 + 唯一组合组件 |
| 旧页面头样式与新组件冲突 | 删除主页面旧标题结构，保留页面业务 CSS |
| 长文案造成移动端溢出 | `min-width:0`、自动换行、无固定内容宽度、全尺寸 E2E |
| 抽屉抢占全局 Escape 或焦点 | 组件局部监听、打开保存触发元素、关闭恢复焦点 |
| 页面说明被全部删除导致现场风险 | 搜索并保留操作附近的风险 Alert/文字 |
| 页面无权限时仍渲染入口 | 依赖现有路由守卫；无权限 E2E 断言无页面头 |
| UX-005 导航和听记回归 | 全量 Vitest 和 Playwright，不删除旧断言 |

## ↩️ 回滚

- 应用层回滚到 `req-ui-ux005-final3` 即恢复旧页面头。
- 本功能无数据库结构或数据变化，不需要执行迁移 down。
- 部署前数据库备份仍保留，用于验证恢复能力。
- 冻结标签 `req-ui-ux005-frozen-v1` 与 `req-ui-step8-frozen-v1` 均不移位。

## ✅ 架构自审要点

- 共享高内聚：内容目录、组件状态、视觉呈现分离。
- 低耦合：页面只传标题、范围、主操作和目录标识。
- 数据权威不变：帮助内容不进入业务存储。
- 权限仍由原路由和 API 负责，不以隐藏帮助入口代替授权。
- 客户端不包含密钥、令牌或生产敏感数据。
