# UX-004-A 事件确认与流程发起变更计划

> 状态：`COMPLETE_DEPLOYED_AND_FROZEN`
>
> 功能：`UX-004` 业务可编辑的人工确认中心（2A：事件确认与流程发起）
>
> 分支：`feature/ui-step2a-event-confirmation`
>
> 基线：`main@62052fb8f422550f503d4383f72f5d58759ac2a6`
>
> 目标发布：`req-ui-step2a-final1`
>
> 目标冻结标签：`req-ui-step2a-frozen-v1`

## 🎯 目标

把事件收件箱的“接受/拒绝 Agent 建议”升级为可编辑的真人确认闭环：

```text
选择项目
 → 选择负责人
 → 设置上海时区截止时间
 → 选择 P0/P1/P2
 → 编辑任务内容
 → 决定是否创建任务
 → 关联已有流程或发起新流程
 → 预览影响与不会执行的动作
 → 单事务确认
```

## 🧱 实现范围

1. 前端事件卡增加项目、项目成员、截止日期时间、优先级、可编辑内容、创建任务开关、
   已有流程选择和新流程选择。
2. 候选数据使用业务名称、用户姓名和流程名称；UUID 只作为内部请求值。
3. 上海时区统一格式化、解释和回写，避免浏览器时区或次日偏移。
4. 最终确认使用独立影响预览，缺负责人或截止时间时禁止提交。
5. 扩展确认请求，支持 `WorkflowDefinitionId`、`WorkflowVersionId`；复用已有
   `ProjectId`、`AssigneeId`、`DueAt`、`Priority`、`Content`、`WorkflowInstanceId`。
6. 新增 Application Handler，在同一事务中编排新流程启动和事件确认；Vue 只调用一个写接口。
7. 确认结果返回事件、项目任务、项目和流程实例；项目关系保存事件来源、任务和流程。
8. 保持高风险永久人工边界；不因流程选择或任务开关放宽风险动作。

## 🧭 架构决策

- 新流程启动继续复用现有 `StartWorkflowInstanceHandler` 的业务规则，提取事务内执行入口，
  不复制流程定义校验、处理人解析、任务创建、审计或 Outbox。
- 事件确认继续复用 `SqlEventInboxService` 的项目范围、处理人、项目任务、来源关系和审计规则，
  提取事务内暂存入口，不复制项目任务状态逻辑。
- 新 `ConfirmInboxEventAndStartWorkflowHandler` 只做跨聚合编排、统一幂等和事务边界。
- 共用同一 scoped `AidtDbContext`、`IUnitOfWork` 和审计仓储，任一写入失败统一回滚。
- 同一事件已有确认或任务时拒绝重复派发；数据库唯一约束作为并发兜底。

## 📌 影响分析

| 范围 | 变更 | 验证 |
|---|---|---|
| Application | 新增确认并发起流程 Handler；提取流程/事件事务内执行入口 | 单元编译、权限、参数校验 |
| API | 新增 `POST /api/v1/inbox/{id}/actions/confirm-and-start-flow` | OpenAPI、401/403/409/422 |
| Infrastructure | 事件确认和流程启动共享事务；项目关系与审计原子提交 | SQL/API 集成、失败回滚 |
| Frontend | 可编辑确认表单、候选加载、影响预览、上海时区 | 类型、Vitest、Playwright |
| 数据 | 复用现有事件、建议、任务、流程、项目和关系表 | 无新迁移；62 张应用表保持 |
| 权限 | 同时校验事件确认、项目管理和流程提交；处理人须在项目内 | 跨部门/跨项目/无权限测试 |
| 审计 | 记录事件确认、任务创建、流程启动、影响摘要和不会执行动作 | 时间线与 SQL 反查 |

## 🚫 不在范围

- 不改造听记、MCP、Agent 等其他确认来源。
- 不新增第二套流程引擎、项目任务表或前端临时状态存储。
- 不允许 Agent 自动确认、自动选择负责人或自动发起高风险流程。
- 不改变付款、质量放行、配方、设备控制、安全联锁、合同和重大赔付边界。
- 不修改历史标签、发布包、迁移 001–010 或数据库备份。

## 🧪 验收

- 修改负责人和截止时间后创建任务，刷新保持。
- 创建任务并发起流程，刷新后事件、任务、流程和项目互相可反查。
- 流程启动失败时，事件仍待确认，且无任务、流程、关系或审计半成品。
- 跨部门项目、非项目成员负责人、无确认权限和无流程提交权限均被拒绝。
- 1440、1280、390px 可完成编辑、预览和确认。
- 原后端与 MCP 138/138、正式部署 E2E 23/23 不回归。
- 源码全量门禁、正式部署、回滚、数据库恢复和目标发布/冻结全部留证。
