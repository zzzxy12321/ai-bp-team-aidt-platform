# AIDT 岗位工作台模板目录

> Feature：`WS-002`
>
> 首批版本：6 个系统保留模板、31 张真实数据卡片
>
> 模板版本：`Workspace.WorkbenchTemplateVersion`

## 🧭 使用原则

- 模板只组合当前已实现的业务能力，不复制部门、项目、流程、文件或对象数据。
- 导航决定“有哪些入口”，工作台模板决定“进入部门后首屏显示什么”。
- 匹配顺序固定为用户级 → 角色级 → 部门级 → 组织默认。
- 同一范围按优先级、排序、发布时间和稳定编码确定唯一模板。
- 卡片查询再次执行原业务权限、组织/部门/项目/环境范围和永久人工边界。
- 无匹配模板时回退通用部门工作区。

## 🃏 首批卡片类型

| 类型 | 真实来源 | 主要权限 |
|---|---|---|
| `work_items` | `GET /api/v1/my-work` | `dashboard:read` + 来源权限 |
| `workflow_tasks` | 流程任务与 `GET /api/v1/my-work` | `workflow-task:read` |
| `project_portfolio` | 项目服务 | `project:read` + 部门/成员范围 |
| `project_tasks` | 统一事项中的项目任务 | `project-task:read` |
| `business_objects` | 业务对象只读查询 | `business-object:read` + 部门/环境 |
| `recent_files` | 文件元数据只读查询 | `file:read` + 部门/环境 |
| `minutes` | 听记来源只读查询 | `minutes:read` + 部门/环境 |
| `overdue_risks` | 统一事项中的逾期/高风险 | 来源原权限 |
| `team_pending` | 部门流程任务 | 部门负责人 + `workflow-task:read` |
| `ai_activity` | AgentRun 只读查询 | `agent-run:read` + 部门/环境 |

## 🧱 已登记但尚未接入

当前注册中心没有“三单匹配”“自动付款”“自动质量放行”“DCS 联锁”等真实能力。
模板只能保存 `CapabilityState=NotConnected` 的说明卡片，页面必须显示“能力尚未接入”，
不得生成模拟数量、完成率或虚假流程。

## 🛡️ 配置边界

- 系统模板可复制，不能删除或停用。
- 平台管理员维护组织级和系统模板。
- 授权部门负责人可复制并维护本部门业务模板。
- 发布生成不可变版本；草稿不影响线上。
- 创建、修改、复制、发布、停用、恢复和分配写追加式审计。
