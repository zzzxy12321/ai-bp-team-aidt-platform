# DEPT-WF-001 变更计划

状态：`complete_deployed_and_frozen`

## 🎯 目标

把现有“模块集合式后台”升级为部门优先工作空间，并在同一套业务对象、Elsa 流程、
任务、文件、听记、数字员工、权限和审计体系内，完成可视化流程模板设计、
节点级动态表单和四部门真实试点闭环。

## 🧭 分阶段门禁

1. `8A`：数据清场、部门导航、会话权限刷新与测试隔离。
2. `8B`：流程模板生命周期、节点模型、动态表单、任务冻结版本和审批联动。
3. `8C`：PMS 式可视化流程设计器与员工运行时动态表单。
4. `8D`：交付中心、研发、供应链、财务四部门试点闭环。

## 📌 8A 范围

- 创建数据库备份并执行 `RESTORE VERIFYONLY`。
- 只读盘点导航、流程配置及测试残留，不按名称模糊物理删除。
- 测试导航使用状态退役/软删除或明确测试标记；测试配置使用安全退役或测试标记。
- 审计、历史流程、任务和证据只保留，不物理删除。
- 导航从已注册资源生成三层结构：公司公共入口、部门、平台治理。
- 删除 `AppLayout.vue` 中重复硬编码业务入口。
- 支持有权限部门、默认展开、收藏、排序和隐藏；系统入口不可删除。
- 401/403 与权限变更不能降级成空数组，必须提示重新登录。
- 补充交付中心 Demo 导航，不冒充正式组织主数据。

## 📌 8B 范围
