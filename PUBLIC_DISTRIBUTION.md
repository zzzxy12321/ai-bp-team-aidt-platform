# AIDT Complete Platform - Public Distribution

This repository contains the complete AIDT formal-system source snapshot for the AI-BP team.

The companion demo, documentation catalog, and reusable standards repository is available at [ai-bp-team-reusable-system-by-zxy](https://github.com/zzzxy12321/ai-bp-team-reusable-system-by-zxy).

## Quick access

Start with the standalone reading folder: [`使用前先看这里/`](./使用前先看这里/). It contains the catalog workbook first, followed by numbered copies of all 45 documents. The original rule documents in the rest of the repository remain unchanged.

## Access model

- Anyone can browse, clone, or download the repository.
- Public visitors have read-only access.
- Visitors may modify their own local copy or fork.
- Direct pushes to this repository are limited to the repository owner.
- Required credentials, runtime databases, dependencies, build output, and production data are not included.

## Included

- ASP.NET Core modular-monolith backend
- Vue 3 frontend
- SQL Server schema and migrations
- Deployment and rollback scripts
- Automated tests and test evidence
- Project requirements, feature map, standards, templates, prompts, findings, and progress records

The repository is public, but real formulas, customer data, costs, quotations, process parameters, credentials, interface keys, and production records must never be committed.
