# WorkflowPersistenceAndSecurity DBA 审核检查点

> 审核状态：Demo 技术验证通过；生产 DBA 审核待甲方  
> 执行状态：`applied_verified`

## 🎯 变更目的

为业务对象补充组织数据范围，并增加写命令幂等记录，为流程持久化、权限范围和重复提交保护提供数据库约束。

## 🗂️ 影响范围

- `BusinessObject`：增加组织范围字段。
- `Integration`：新增 `IdempotencyRecord`，应用表总数由 34 增至 35。
- 涉及唯一约束、索引和现有数据回填。

## 🔍 审核项

- [ ] 现有业务对象能够安全回填组织范围。
- [ ] 非空约束和回填顺序不会导致已有数据迁移失败。
- [ ] 组织范围字段具有查询与权限过滤所需复合索引。
- [ ] 幂等范围与幂等键组合唯一，且键长符合接口契约。
- [ ] 幂等记录清理策略和保留周期已确认。
- [ ] 升级 SQL 可重复执行或在重复执行时明确失败。
- [ ] 回滚 SQL 不静默删除仍被审计引用的数据。
- [ ] 迁移前完成全量备份并记录恢复点。
- [ ] 在空库和上一版本库分别演练。
- [ ] 锁表时间、维护窗口和失败中止策略已确认。

- 已在独立迁移测试库完成 up/down。
- 生产排序规则、容量、锁表时间和维护窗口仍需甲方 DBA 审核。
- 不把 Demo 验证等同于生产 DBA 签认。
