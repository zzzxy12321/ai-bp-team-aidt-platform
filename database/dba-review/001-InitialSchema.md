## 🔍 审核项

- [ ] 数据库排序规则符合甲方标准。

- [ ] 34 张应用表与外键顺序正确。
- [ ] 所有金额列为 `decimal`，时间列为 UTC `datetime2`。
- [ ] JSON 列有 `ISJSON` 检查。
- [ ] 唯一索引覆盖业务键和幂等键。
- [ ] 审计表对普通业务账号只允许插入/查询，不允许更新/删除。
- [ ] 迁移前有完整备份和恢复点。
- [ ] 空库和上一版本库迁移方案已演练。
- [ ] 执行时长、锁表风险与维护窗口已确认。
- [ ] 回滚 SQL 已由 DBA 复核。
- [ ] 执行后对象、索引、约束和迁移历史校验通过。
